# LM Studio Web Chat

A fully local, web-based chat interface for **LM Studio**.  
Chat with your models directly from your browser with **dark theme, coloured bubbles, typing animation, and auto-scroll**.

---

## Features
- Fully local — runs on your computer, no CORS issues  
- Dark theme with colored chat bubbles  
- Animated typing for AI responses  
- Auto-scroll to newest message  
- Minimal dependencies (Python 3 standard library)

---

## Requirements
- [LM Studio](https://lmstudio.ai/) running locally on your Mac (default port `1234`)  
- Python 3

---

## Installation & Usage

1. Clone the repository:
git clone https://github.com/yourusername/lmstudio-web-chat.git
cd lmstudio-web-chat

2. Make sure LM Studio is running on your Mac (default port 1234).

3. Run the web chat server:
python3 lm_web_chat.py

4. Open your browser and go to:
http://localhost:8080

5. Start chatting!
